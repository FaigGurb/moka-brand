# CLAUDE.md — MOKA Brand Experience

## What this is
Concept brand site for MOKA Coffee Roastery (Baku). Test project, not the official site. Three languages: Azerbaijani (default, `/`), English (`/en/`), Russian (`/ru/`).

## Layout
- `web/` — Next.js 15 source (static export, basePath `/moka-brand`). Edit here.
- Repo root `index.html`, `_next/`, `404*`, `index.txt` — GENERATED by `cd web && npm run deploy`. Never edit by hand.
- `ar/` — AR hub (`index.html`) + `card/` (MindAR image), `table/` (model-viewer, GLBs in `ar/models/`, regenerate with `ar/models/source/generate.html`), `selfie/` (MindAR face + photo capture). Shared drawing/i18n helpers in `ar/shared/` (logo geometry mirrors `web/src/lib/logo.ts`). `game/` — games hub + `line/`, `rain/`, `memory/` (shared `game/shared/game.css`; sounds in `game/shared/sound.js` = window.MokaSound, Web Audio synth + the brand sound logo at the result, mute toggle remembered in `moka-sound`). `club/` — MOKA Club concept wallet: `club.js` (window.MokaClub, localStorage `moka-club-v1`, daily cap 100/game, AR +25) used by games, AR pages and the site's `ClubCard`. `v1/` (previous site). All standalone static pages; the deploy script never touches them.

## Commands (run in `web/`)
`npm run dev` · `npm run lint` · `npm run typecheck` · `npm run build` · `npm run deploy` (build + copy export to root). Then commit and push; GitHub Pages serves `main` root.

## Conventions
- Fonts: League Spartan (display) + Mulish (text) only. Both cover the full Azerbaijani alphabet. Before adding any font, verify it has Ə/ə (many popular fonts, e.g. Jost, Lato, Rubik, Outfit, do not).
- Colours come from the `@theme` block in `web/src/app/globals.css`, mirroring the MOKA design system tokens. Day-palette names: Səhər (oak), Günorta (bamboo), Axşam (copper), Şəhər (concrete), Nar (rust).
- Logo geometry lives in `web/src/lib/logo.ts`; SVG and 3D both derive from it. Every letter is split by the signature line (y 74.5–79.5).
- GSAP only inside `useGSAP` with `gsap.matchMedia()`. Pinned/scrubbed stories run on every screen size (phones included, using `100svh` and `anticipatePin`); only `prefers-reduced-motion` turns them off (use Tailwind `motion-safe:`/`motion-reduce:` for the matching layout). `ScrollTrigger.config({ ignoreMobileResize: true })` stays on.
- 3D hero: mouse tilt on desktop, automatic sway on touch screens (`useTouch`), lower DPR on phones.
- Three.js only via `next/dynamic` with `ssr: false`; keep the SVG fallback working.
- Bean story (`sections/BeanStory.tsx` + `beans/BeanStoryScene.tsx`): one scroll progress drives every phase; boundaries live in `beans/phases.ts` (shared by scene and captions — keep it free of three imports). Bean geometry/roast colours in `lib/bean.ts`. Canvas renders only while on screen (`frameloop`).
- Page-wide beans: `beans/BeanField.tsx` (fixed, pointer-events none, hidden over `#top`/`#proses`). All bean scenes share `lib/pointer.ts` (mouse + touchmove) and `lib/beanPhysics.ts` (push/spring). Keep the field sparse and at the edges so copy stays readable.
- Smooth scroll: Lenis in `SmoothScroll.tsx`, driven by `gsap.ticker`; pins use `scrub: 1`. Anchor offset −72px for the nav.
- Desktop nav shows 8 links from `xl`; below that the menu button is used.
- Brand boards in `public/brand/` are renders of the design canvas (Azerbaijani text); captions are translated in `dict.ts` (`apps.insta.posts`).
- Performance: every Canvas gets `frameloop` from visibility; `perfTier()` (lib/perf.ts) picks the lite path on touch/weak devices (DPR ≤1.5, MeshStandard instead of Physical, fewer instances). Page-wide BeanField, grain and nav blur are desktop-only. Don't add always-on full-screen layers on mobile.
- Fonts are self-hosted (`@fontsource-variable/*` in layout.tsx; static pages use `/fonts/fonts.css`). Don't reintroduce Google Fonts links.
- Publishing: page metadata via `pageMeta()` in `lib/meta.ts` (canonical, hreflang, OG, robots). `NEXT_PUBLIC_CONCEPT` keeps `noindex` until MOKA approves. Secondary pages use `components/pages/PageShell` and `Nav sub="menu/"`. Checklist: `docs/QA.md`.
- Effects live in `components/fx/` (Preloader once per session, Cursor for fine pointers, ScrollLine, Marquee) plus `.grain` in globals.css; all off for reduced motion.
- MOKA Club is a demo: never present codes as real discounts; keep the "concept" notes.
- No invented facts: origins, tasting notes, prices, farmer/artist names are marked as samples or `[placeholders]`.
- Links to static pages go through `links(locale)` in `web/src/lib/site.ts` (basePath-aware, adds `?lang=`).
- All copy lives in `web/src/i18n/dict.ts` (az is the source; en/ru must have the same shape). Components read it with `useI18n()`. Day-palette brand names stay Azerbaijani in every language with a translated subtitle.
- `ar/` and `game/` carry their own az/en/ru strings; language comes from `?lang=` or `localStorage['moka-lang']`, and their back buttons return to the matching language home.
- Russian headings: League Spartan has no Cyrillic, so `Montserrat` (self-hosted) sits next in the display stack.

## Working method
Follow `docs/ENGINEERING.md` (audit → prioritise → implement → verify; honest reporting; definition of done). Run `npm run check` + `npm run build` and the browser checks in `docs/tools/qa/` before deploying. Device checklist: `docs/QA.md`.

- Brand book: `/brand/` (`components/pages/BrandPage.tsx`, copy in `src/i18n/brand.ts`, same shape in az/en/ru). Downloadable kit in `web/public/brand-kit/` (logo SVGs, tokens, sound logo, logo animation, brand book PDFs, `print/` business card · cup sleeve · bag label · A3 menu, `social/` Story/Reels templates) — regenerate with the scripts in `docs/tools/` (`render_print.py`, `render_social.py`, …).
- Living background: `fx/DayAmbient.tsx` sets `--day`/`--day-rgb` from Baku time (`lib/day.ts`); `.day-glow`/`.day-wash` classes tint sections; `fx/CremaBackground.tsx` is a plain-WebGL shader for dark sections (in-view only, low res/fps, still frame for reduced motion).
- AR libraries are vendored in `/vendor/` (no CDN at runtime).
