# CLAUDE.md — MOKA Brand Experience

## What this is
Concept brand site for MOKA Coffee Roastery (Baku). Test project, not the official site. Three languages: Azerbaijani (default, `/`), English (`/en/`), Russian (`/ru/`).

## Layout
- `web/` — Next.js 15 source (static export, basePath `/moka-brand`). Edit here.
- Repo root `index.html`, `_next/`, `404*`, `index.txt` — GENERATED by `cd web && npm run deploy`. Never edit by hand.
- `ar/` — AR hub (`index.html`) + `card/` (MindAR image), `table/` (model-viewer, GLBs in `ar/models/`, regenerate with `ar/models/source/generate.html`), `selfie/` (MindAR face + photo capture). Shared drawing/i18n helpers in `ar/shared/` (logo geometry mirrors `web/src/lib/logo.ts`). `game/` — games hub + `line/`, `rain/`, `memory/` (shared `game/shared/game.css`; sounds in `game/shared/sound.js` = window.MokaSound, Web Audio synth + the brand sound logo at the result, mute toggle remembered in `moka-sound`). `club/` — MOKA Club concept wallet: `club.js` (window.MokaClub, localStorage `moka-club-v1`, daily cap 100/game, AR +25) used by games, AR pages and the site's `ClubCard`. `v1/` (previous site). All standalone static pages; the deploy script never touches them.

## Commands (run in `web/`)
`npm run dev` · `npm run lint` · `npm run typecheck` · `npm run build` · `npm run deploy` (build + copy export to root). Then commit and push; GitHub Pages serves `main` root.

## Conventions
- Fonts: League Spartan (display) + Mulish (text) only. Both cover the full Azerbaijani alphabet. Before adding any font, verify it has Ə/ə (many popular fonts, e.g. Jost, Lato, Rubik, Outfit, do not).
- Colours come from the `@theme` block in `web/src/app/globals.css`, mirroring the MOKA design system tokens. Day-palette names: Səhər (oak), Günorta (bamboo), Axşam (copper), Şəhər (concrete), Nar (rust).
- Logo geometry lives in `web/src/lib/logo.ts`; SVG and 3D both derive from it. Every letter is split by the signature line (y 74.5–79.5).
- GSAP only inside `useGSAP` with `gsap.matchMedia()`. Scrubbed stories run on every screen size; their scenes are CSS `position: sticky` inside a taller section (Concept 260svh, DayPalette `.d-track`, Tiers height = screen + sideways distance), never a GSAP `pin` (pins stutter under touch momentum on phones); `scrubFor()` (lib/gsap.ts) follows the finger directly on touch screens and smooths only for wheels; moving strips get `force3D` + `will-change` (iOS repaints wide strips in pieces otherwise); the film skips its camera work while a content section covers it; no always-on animated glow on phones; only `prefers-reduced-motion` turns them off (use Tailwind `motion-safe:`/`motion-reduce:` for the matching layout). `ScrollTrigger.config({ ignoreMobileResize: true })` stays on.
- Three.js only via `next/dynamic` with `ssr: false`; keep the SVG fallback working.
- Coffee journey = one film under the first part of the page (photoreal, no real-time 3D): `sections/BeanStory.tsx` configures `cinema/FilmJourney.tsx`, which wraps the hero (`lead`), seven chapter sections (`data-film-stop`: green → dark → crack → grind → pour → Chemex → cup; captions `beans.steps` + `beans.final`) and the content that scrolls over the held frames (Roast after crack, BrewGuide after Chemex, Tiers after the cup). A sticky full-screen backdrop plays `CLIPS.journey` (`lib/clips.ts`, 541 frames at 18 fps in `public/film/journey/<w>/` (960/1280/1920; every frame upscaled 4× with Real-ESRGAN, `docs/tools/film/upscale.py`, because the Kling clips are 720p; capable screens pick `pickCoverWidth(film, 0.75, 2400)`, phones 0.42, one set smaller when `navigator.connection` reports < 3 Mbps or save-data), six Kling 3.0 start→end-frame transitions joined with `docs/tools/film/chain.sh journey 18 "960 1280" 80 "unsharp=5:5:0.45:5:5:0" t0…t5`). The film moves at one steady speed with the scroll (keyframes linear, about `SPAN` screens per stop; it holds only while a content section covers it), one framerate-independent damping layer on top of Lenis (`FOLLOW` ≈ 0.075 per 60 Hz frame, the awwwards-3d lerp loop) so the film glides on after input; stops are about `SPAN` = 1 screen apart. One gesture = one stop: inside the film every wheel gesture (events >200 ms apart; a trackpad's inertia tail belongs to its gesture), swipe or arrow key moves the goal one stop and the page glides there in ~2–2.5 s, close to the clips' own slow-motion pace, on a sine ease (even middle; `STEP_*`) (`lenis.scrollTo`, Lenis via `lib/lenis.ts`; the film follows the eased scroll almost directly, `FOLLOW_STEP`, and the camera leans in with its speed, `PUSH`); gestures during a move add stops (two scrolls = two stops, no pause between) — never lock the scroll or swallow gestures (an earlier locking version felt jerky). Touch steps start a frame after touchend (Lenis resets its animation on touchend). Content sections scroll freely. Chapter titles are pinned for their section and driven by the film position (`--o`): their words rise out of depth one by one (`.film-word` in globals.css). Zigzag on wide screens: titles alternate left/right (vertically centred) and the picture slides away from them (`ZIG`/`ZOOM` on `data-film-cam`, side shades `data-film-shade`); phones keep titles at the foot. The pointer drift only on capable fine-pointer screens. Enky-style layers (wide capable screens): a giant scene word per chapter (`.film-big`, dim warm colour with `mix-blend-mode: lighten`, so it shows only on the dark backdrop and reads as behind the subject; never on the last stop, nothing may show through MOKA's K), a fixed chapter index on the right (`data-film-index`, hidden over the opening and content sections, click = eased jump), and fact pills under captions (`beans.steps[].tags`, real facts only). FrameStore fetches where the visitor is (a 16-frame skeleton, then the next two stops coarse to fine, then the rest nearest first; from page load) and keeps a dense decoded window plus every 4th/8th further out (smaller on phones and for sets ≥1600), so fast flicks land on ready frames. At rest the camera breathes (`BREATH` 9 s, `BREATH_ZOOM`, `BREATH_PAN` on wide screens only) so a held frame never looks frozen. Camera: `ZOOM` 1.08, `ZIG` 3.5, `PUSH_MAX` 0.04 (less upscaling). Measure on a throttled line with the QA scripts before changing the loader. No still swaps (one continuous picture), neighbouring frames are blended in quarter steps on capable screens, phones step through frames. Content sections fade in/out of the film with gradients (`tone`). The film ends on a blank cup (`docs/tools/film/src/cup-blank.webp`) and the vector K (`public/cinema/cup-k.webp`, cut from the cup still) fades onto it — never let a generator draw MOKA's logo. Stills: `public/cinema/` (`docs/tools/film/stills.py`, `lib/cinema.ts`). Hero (`hero/Hero.tsx`): photoreal still + `LoopVideo` (hero beans; source set only after window load + idle, smallest width on the low tier, so it never competes with LCP) + official `Lockup`; `cinema/BeanRain.tsx` until the loop plays. Loops: `LOOPS` in `lib/cinema.ts`, `public/cinema/video/<name>-<w>.mp4|webm` (`docs/tools/film/loop.sh`). The film's h2 (`heading`) is rendered before the chapter h3s (heading order); `CoverFrame` stays hidden until measured (no CLS). Section titles outside the film get one entrance (`fx/HeadingReveal.tsx`: plain-text titles split into words that rise out of masks with a stagger, the eyebrow settles, the following paragraph comes a beat later). Hero CTA "watch the film" fires `moka:tour`: FilmJourney plays the film stop by stop (holds `HOLD`, glides over content sections, stops at the cup or on any wheel/touch/key/pointer). Sound (optional, off by default): `lib/sound.ts` + `SoundToggle` in the nav; shares localStorage `moka-sound` with the games but the site plays only on an explicit 'on'; a soft synthesized pour per film step, the brand sound logo when the K lands on the cup, a rate-limited tok for falling beans; never use audio ripped from Instagram reels (likely licensed music). Delight, one each (from the coffee-site research): hero "drop a bean" toy (`fx/BeanDrop.ts`, hero bean sprites, gravity + bounce, canvas only while beans exist); MOKA's official slogan as a giant outline drifting behind the packaging gallery (`.t-word` in `Tiers.tsx`, never on the packs); both slogans on a scroll-turned ring around the K in FinalCta (desktop only). Concept pin is `+=160%` and each letter opens along the signature line as the line reaches it. Store ends with three real café photos from MOKA's reels (`public/cinema/bar/sign|led|window.webp`; no frames showing children). Real footage: `sections/Bar.tsx` (#bar, right after the film) shows MOKA's own bar ritual from their Instagram reel (`LOOPS.bar`, `public/cinema/bar/`, credited in `bar.credit`); never present generated imagery as MOKA's. Type rules: `.eyebrow` is a quiet sentence-case grey line (no tracked capitals, one phrase, no `A · B` chains); buttons/links in sentence case; section h2 `clamp(40px,6vw,96px)`. Page order: film zone (hero → … → packaging), then Bar, Concept, DayPalette, Partners, Store, Marquee, Apps, Experience, FinalCta; `NAV_IDS` follows it.
- Smooth scroll: Lenis in `SmoothScroll.tsx`, driven by `gsap.ticker`; pins use `scrub: 1`. Anchor offset −72px for the nav.
- Desktop nav shows 8 links from `xl`; below that the menu button is used.
- Brand boards in `public/brand/` are renders of the design canvas (Azerbaijani text); captions are translated in `dict.ts` (`apps.insta.posts`).
- Performance: every Canvas gets `frameloop` from visibility; `perfTier()` (lib/perf.ts) picks the lite path on touch/weak devices (DPR ≤1.5, MeshStandard instead of Physical, fewer instances). Grain and nav blur are desktop-only. Don't add always-on full-screen layers on mobile.
- Fonts are self-hosted (`@fontsource-variable/*` in layout.tsx; static pages use `/fonts/fonts.css`). Don't reintroduce Google Fonts links.
- Publishing: page metadata via `pageMeta()` in `lib/meta.ts` (canonical, hreflang, OG, robots). `NEXT_PUBLIC_CONCEPT` keeps `noindex` until MOKA approves. Secondary pages use `components/pages/PageShell` and `Nav sub="menu/"`. Checklist: `docs/QA.md`.
- Effects live in `components/fx/` (Preloader once per session, Cursor for fine pointers, ScrollLine, Marquee) plus `.grain` in globals.css; all off for reduced motion.
- MOKA Club is a demo: never present codes as real discounts; keep the "concept" notes.
- No invented facts: origins, tasting notes, prices, farmer/artist names are marked as samples or `[placeholders]`.
- Links to static pages go through `links(locale)` in `web/src/lib/site.ts` (basePath-aware, adds `?lang=`).
- All copy lives in `web/src/i18n/dict.ts` (az is the source; en/ru must have the same shape). Components read it with `useI18n()`. Day-palette brand names stay Azerbaijani in every language with a translated subtitle.
- `ar/` and `game/` carry their own az/en/ru strings; language comes from `?lang=` or `localStorage['moka-lang']`, and their back buttons return to the matching language home.
- Russian headings: League Spartan has no Cyrillic, so `Montserrat` (self-hosted) sits next in the display stack.

## Working method
Follow `docs/ENGINEERING.md` (audit → prioritise → implement → verify; honest reporting; definition of done). Run `npm run check` + `npm run build` and the browser checks in `docs/tools/qa/` before deploying. Device checklist: `docs/QA.md`.

- Brand book: `/brand/` (`components/pages/BrandPage.tsx`, copy in `src/i18n/brand.ts`, same shape in az/en/ru). Downloadable kit in `web/public/brand-kit/` (logo SVGs, tokens, sound logo, logo animation, brand book PDFs, `print/` business card · bean card · A3 menu, `social/` Story/Reels templates) — regenerate with the scripts in `docs/tools/` (`render_print.py`, `render_social.py`, …).
- Tone bands (home page): `fx/ToneShift.tsx` — `ToneBand tone="ink"|"paper"` wraps sections in `Site.tsx` (MOKA's official black ↔ cup white); `.tone-paper` turns the colour tokens over so dark-ground sections read black on white, `.tone-ink` makes espresso neutral black (espresso stays in the brand book/print); band sections are transparent and `ToneShift` blends `--page-bg` with the scroll. Partner logo plates are always white (`plateTone`). FilmJourney's wrapper is `overflow-clip` (its sticky backdrop would hang a screen over the next band).
- Living background: `fx/DayAmbient.tsx` sets `--day`/`--day-rgb` from Baku time (`lib/day.ts`); `.day-glow`/`.day-wash` classes tint sections; `fx/CremaBackground.tsx` is a plain-WebGL shader for dark sections (in-view only, low res/fps, still frame for reduced motion).
- AR libraries are vendored in `/vendor/` (no CDN at runtime).

## Working with Claude Code
- Token rules:
  - Read only the files a task names (plus CLAUDE.md); no repo-wide scans; grep only for named symbols.
  - Read big files (`web/src/i18n/dict.ts`, `brand.ts`) in parts.
  - One task per session; final report max 10 lines, no code dumps.
- Skills for this project: use only when the step needs them, never others.
  - `high-end-visual-design` — visual/UI changes only.
  - `review` (gstack) — before committing code changes.
  - `qa-only` (gstack) — after a deploy, to check the live site.
  - `headroom` — reading large files.
- Deploy only when the task says "DEPLOY: yes": `cd web && npm run check && npm run build && npm run deploy`, then commit and push. Otherwise commit only.
- Reports go in Azerbaijani.
- Task state: read `docs/TASK.md` at the start; at the end update its Status/Verification/Next step (keep it short) and commit it with the work. It is the handoff with the planning chat.
